# Changelog

All notable changes to FormReady will be documented in this file.

## [1.0.0] - 2026-11-21

### Initial Release
- Target-size image compressor with binary-search quality optimization (10 KB to 1 MB).
- Signature fixer with automatic whitespace detection and background contrast enhancement.
- Passport photo preparation tool with face framing guide and printable 4x6 grid.
- Browser-based PDF tools: Images to PDF, PDF merge, PDF split, and stream optimization.
- Application presets directory covering UPSC, SSC, IBPS, NEET UG, JEE Main, GATE, US Visa, and Passport Seva.
- Multi-language UI support for English, Hindi, and Telugu.
- 100% client-side privacy architecture with automated network audit verification.
- Complete static build export ready for zero-backend Vercel deployment.
